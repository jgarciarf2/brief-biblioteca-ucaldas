# API Biblioteca Ucaldas

Proyecto backend en Node.js + TypeScript + Express con datos en memoria.

## Requisitos

- Node.js 18+
- npm

## Instalacion

1. Instalar dependencias:

```
npm install
```

2. Ejecutar en desarrollo:

```
npm run dev
```

3. Compilar y ejecutar:

```
npm run build
npm start
```

## Notas

- Este proyecto usa una arquitectura limpia (entidades, casos de uso, controladores y rutas).
- No hay base de datos; todo se maneja en memoria.
